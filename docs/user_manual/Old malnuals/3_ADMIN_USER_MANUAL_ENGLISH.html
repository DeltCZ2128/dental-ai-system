SECTION 3: ADMINISTRATOR PORTAL USER MANUAL

Chapter 1: Master Administrative Control Overview

The Administrator Portal provides master control over clinic operations, including appointment approvals, dentist schedule/absence management, emergency patient reassignments, QR code check-ins, medical record printing, machine learning demand forecasting, and system backups.

Chapter 2: Executive Dashboard & Operational Analytics

Operational Counters: Real-time metrics for Today's Appointments, Pending Approvals, Active Dentists, and Registered Patients.

Machine Learning Demand Forecasting Module:

• Uses a Linear Regression model evaluating historical 90-day booking data.

• Displays forecasted demand levels (Low, Medium, High) for upcoming operational days.

• Provides AI-based rescheduling suggestions to distribute patient traffic away from high-demand days.

  1. Master Operational Metrics [Arrow 1 - Blue]: Monitor Today's Appointments, Pending Approvals, Active Dentists, and Patients.
  2. Demand Distribution Analytics [Arrow 2 - Green]: Procedure utilization breakdown and workload balance overview.
  3. Administrative Navigation [Arrow 3 - Purple]: Master access to Appointments, Dentists, Patients, Reports, and Backup.

Chapter 2.1: 7-Day Machine Learning Demand Forecast

The integrated machine learning module applies a Linear Regression Algorithm ($y = mx + b$) trained on 90 days of historical booking data. It forecasts appointment volume for the next 7 operational days, classifying days into Low, Medium, or High demand.

The system generates Smart Reschedule Recommendations, allowing administrators to guide walk-in patients or reschedule non-urgent visits to low-demand days to optimize clinic throughput.

  1. 7-Day Forecast Table [Arrow 1 - Blue]: Review projected patient volumes, actual bookings, and demand levels (Low, Medium, High).
  2. Smart Reschedule Suggestions [Arrow 2 - Green]: Actionable recommendations routing flexible appointments to low-demand days.

Chapter 3: Appointment Approvals & Status Control

Go to [Master Appointments] (admin/appointments.php).

Filter lists using sub-tabs: Today, Pending Approvals, Upcoming, and History.

Click [Change Status] on any record to:

• Approve (Confirm): Validates booking and sends confirmation email/notification to patient.

• Check-In: Updates status when a patient physically arrives at the clinic lobby.

• Reschedule: Modifies date/time while performing automated conflict checking.

• Cancel / No-Show: Triggers when a patient misses their slot beyond the 30-minute grace period.

  1. Operational Sub-Tabs [Arrow 1 - Blue]: Filter between Today, Pending Approvals, Upcoming, and Complete History.
  2. Change Status Control [Arrow 2 - Red]: Action button to Approve, Check-In, Reschedule, or Cancel/No-Show (30-min grace period).

Chapter 4: Emergency Patient Reassignment Protocol (Absent Dentist Handling)

When an attending dentist is marked as Absent or takes emergency leave on a date with scheduled appointments:

1. Open the affected appointment in [Master Appointments].

2. The system automatically detects doctor absence and displays a prominent [REASSIGN DENTIST] action alert.

3. Click [REASSIGN DENTIST] to open the dynamic reassignment modal.

4. Select an active, available dentist from the dropdown menu.

5. The system automatically executes real-time conflict-checking to ensure the target dentist:

• Is on duty on that day.

• Has no overlapping appointments or time conflicts.

6. Confirm reassignment. Notification emails/alerts are dispatched to both the newly assigned dentist and the patient.

  1. Doctor Absence Warning [Arrow 1 - Red]: Highlights that the assigned dentist is marked Absent on the appointment date.
  2. REASSIGN DENTIST Action Alert [Arrow 2 - Orange]: Prominent button displayed exclusively when assigned doctor is absent.
  3. Substitute Dentist Dropdown [Arrow 3 - Blue]: Select an available doctor verified free of schedule conflicts.

Chapter 5: Dentist Roster, Flexible Rest Days & Attendance

Navigate to [Dentist Management] (admin/dentists.php).

• Add Rest Day: Click [Add Rest Day] to set recurring or flexible off-days for doctors.

• Mark as Absent: Click [Mark as Absent] for emergency sick leave or unscheduled absences.

• Remove Leave/Rest Day: Click the red Trash Icon next to any record to clear the entry after confirming on the modal dialogue.

  1. Dentist Roster Table [Arrow 1 - Blue]: Directory of all licensed practitioners, specialties, and schedule status.
  2. Add Rest Day Button [Arrow 2 - Green]: Set recurring weekly off-days or flexible rest days.
  3. Mark as Absent Action [Arrow 3 - Red]: Declare emergency leave to trigger automated booking conflict alerts.

Chapter 6: Patient Records Management & Real-Time Search

Access [Patient Directory] (admin/patients.php).

1. Use the Real-Time Search Bar to search by Patient Full Name or Patient ID (e.g., PAT-2026-0001).

2. Click [Print Record] to generate a clean, official medical/dental history document featuring official letterhead and doctor signature lines.

  1. Real-Time Search Bar [Arrow 1 - Blue]: Search dynamically by Patient ID (e.g., PAT-2026-0001) or full legal name.
  2. Print Record Action [Arrow 2 - Green]: Generate official printable dental record with clinic header and signature lines.

Chapter 7: Official Clinic Reports & Letterhead Printing

Go to [Reports Module] (admin/reports.php).

Select report category:

• Appointment Summary Report

• Patient Demographics Report

• Treatment Breakdown & Revenue Report

Click [Print Report]. The system applies a CSS print-scope stylesheet hiding sidebars, navigation bars, and buttons, generating a formatted printout with official Abalos Dental Clinic header and dual approval signature lines (Administrator & Head Dentist).

  1. Report Category Selector [Arrow 1 - Blue]: Choose between Appointment Summary, Patient Demographics, or Treatment Breakdown & Revenue.
  2. Print Report with Letterhead [Arrow 2 - Green]: Trigger clean CSS-formatted printout featuring dual approval signature lines.
